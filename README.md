
# Data Analytics - Proyecto RetailPro

Repositorio de trabajos y proyectos realizados durante el curso de Data Analytics.

## Sobre el proyecto

RetailPro es un proyecto de análisis de ventas que busca transformar datos comerciales en información útil para la toma de decisiones.

El análisis incluye ventas por período, productos, categorías y clientes, además de indicadores como facturación total, cantidad de ventas y ticket promedio.

## Herramientas utilizadas

- SQL: consultas, filtros, agrupaciones y JOINs.
- Power BI Desktop: modelo de datos y visualizaciones.
- Power Query: limpieza y transformación de datos.
- DAX: creación de medidas e indicadores.
- GitHub: organización y documentación del proyecto.
- ChatGPT: apoyo para revisar código y mejorar la documentación.

## Organización del repositorio

- `Modulo_3`: trabajos de modelado de datos.
- `Modulo_4`: consultas SQL y análisis de información.
- `Modulo_5`: consultas SQL con JOINs.

## Cómo ejecutar los scripts SQL

1. Descargar o clonar el repositorio.
2. Abrir el entorno SQL utilizado en el curso.
3. Preparar la base de datos y cargar las tablas correspondientes.
4. Abrir los archivos `.sql` del módulo que se quiera ejecutar.
5. Ejecutar las consultas y revisar los resultados.

Los scripts requieren que las tablas y sus relaciones estén creadas previamente.

## Indicadores del proyecto

- Total de ventas.
- Cantidad de transacciones.
- Ticket promedio.
- Evolución mensual de ventas.
- Ventas por producto y categoría.

## Uso de inteligencia artificial

Se utilizó ChatGPT como herramienta de apoyo para revisar consultas SQL, proponer mejoras y organizar la documentación.

Las sugerencias de IA deben contrastarse con los datos y los resultados de las consultas antes de incorporarlas al análisis.
